## 🌟 Overview
**Personality Predictor** is a web-based project built using **HTML, CSS, Python, and Flask**, powered by **Machine Learning**.  
It analyzes user responses to determine whether they are an **Introvert**, **Ambivert**, or **Extrovert**, providing both **Normal** and **Detailed Analysis** with personalized insights.


🔗 Live Project:
https://dakshin119.pythonanywhere.com

---

## 🧩 Features

- 🎯 **Dual Analysis Modes:** Choose between **Normal Analysis** (quick prediction) or **Deep Analysis** (in-depth personality reflection).  
- 🤖 **ML-Powered Prediction:** Uses a trained model to predict personality type based on user responses.  
- 💬 **Insightful Results:** Displays prediction accuracy, matching personality image, and improvement tips.  
- 🎨 **User-Friendly UI:** Interactive, elegant, and responsive interface built with HTML & CSS.  
- 🔒 **Login & Signup System:** Only authenticated users can take quizzes for secure personalization.  

---

## 🛠️ Technology Stack

- **Frontend:** HTML, CSS  
- **Backend:** Flask (Python)  
- **Database:** MySQL  
- **Machine Learning:** Scikit-learn / TensorFlow  
- **Hosting:** Flask server / Render / Netlify (frontend optional)

## 🚀 Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/Personality-Predictor.git
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Set up the database:**
   ```bash
   # Import login table schema into MySQL
   CREATE DATABASE personalitydb;
   USE personalitydb;
   CREATE TABLE login (username VARCHAR(50), password VARCHAR(50));
   ```

4. **Run the Flask server:**
   ```bash
   python app.py
   ```

5. **Open in browser:**
   ```text
   Navigate to http://127.0.0.1:5000/ and start your personality test!
   ```

## 🧠 Working Flow

```text
1️⃣ User logs in or signs up.  
2️⃣ Chooses between Normal or Deep Analysis.  
3️⃣ Answers a set of behavioral questions.  
4️⃣ The ML model predicts their personality type.  
5️⃣ Result page displays personality type, accuracy, and suggestions.  
```
